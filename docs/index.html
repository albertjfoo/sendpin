Install SendPin on your Karoo 2

Straight from this page. No adb, no terminal, no downloads.

This browser can't do it. Installing needs WebUSB, which only Chromium browsers support — Chrome, Edge or Opera, on a computer or an Android phone. Safari and every iPhone browser are out, because Apple doesn't implement WebUSB. You can still install with adb.

First, on the Karoo

  1. Settings → About → tap the build number seven times
  2. Go back, open Developer options, turn on USB debugging
  3. Plug the Karoo into this computer with a USB cable

Android won't let anything install over USB without that, and there's no way around it from here.

Then

Not connected yet.

Watch the Karoo's screen after connecting — it'll ask whether to allow USB debugging from this computer. Tick always allow and accept.

After it installs

  1. Open SendPin from the Karoo's main menu
  2. Grant location permission when it asks — Android returns no Bluetooth scan results without it, and the extension will look healthy while finding nothing
  3. Check the status line says listening
